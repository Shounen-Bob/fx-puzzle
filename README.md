# fx-puzzle

エフェクターペダルを繋いで戦う、ブラウザで遊べるシレン風ローグライク。

## 🎮 今すぐプレイ

👉 **https://shounen-bob.github.io/fx-puzzle/**

ブラウザを開くだけ。インストール不要。

---

## どんなゲーム？

ギターやシンセで使う「エフェクターペダル」を信号チェーンに繋いで攻撃をカスタマイズしながら、ダンジョンのゴールを目指すターン制ローグライクです。

- **3 種類の攻撃** (突き / ビーム / オーラ) にそれぞれ **4 スロットの直列ペダルボード**
- ペダルの **順番** で結果が変わる (`Delay → Tremolo` と `Tremolo → Delay` で攻撃回数が違う)
- 装着はどこでも可、でも **取り外しは「ピット」の上だけ** — 一度刺したら戻るまで動かせない

## 操作方法

### 移動 / 攻撃

| キー | 動作 |
|---|---|
| `←` `↑` `↓` `→` | 移動 / 向き変更（壁にぶつかると向きだけ変わる） |
| `Q` | 突き (前 1 マス) |
| `W` | ビーム (前方 3 マス貫通) |
| `E` | オーラ (周囲 8 マス) |
| `Esc` | 構え解除 |
| `1` `2` `3` `4` | ペダル取り外し（ピット上でのみ有効） |

### 攻撃は 2 段階

1. `Q` / `W` / `E` を **1 回押す** → 構え状態 (ARM)。攻撃範囲がタイルに表示される（**ターン消費なし**）
2. **同じキーをもう一度押す** → 発射（ターン消費）
3. 違う攻撃キーを押せば構え切替、`Esc` で解除

### ボードの切り替え

画面下の `[Q]` / `[W]` / `[E]` ラベルをクリックすると、編集対象のボードが切り替わります。

### ペダルを装着する

- インベントリのペダルを **空きスロットへドラッグ&ドロップ**
- またはクリックで最初の空きスロットへ自動装着

## ペダルの種類（抜粋）

ペダルはおおまかに以下の役割を持ちます。詳細はゲーム内でペダルにマウスを乗せると見られます。

- **Driver / Tube Driver / Badass Driver** — 武器の素ダメを倍化
- **Phaser** — 凍結（行動不能）を付与、ロックダウン特化
- **Tremolo** — 攻撃回数 +N
- **Delay / GigaDelay** — 左隣のペダルを赤字回数ぶん追加適用（指数的ブースト）
- **Booster / Overdrive / Stack** — 左隣の赤字を ×乗算
- **Lift / Push** — 左隣の赤字を +加算
- **Trim / Cut** — 左隣の赤字を −減算（解除や調整に）
- **Preamp / Power Supply** — 命中時 / 歩行時に HP リジェネ（パッシブ）
- **Triplet Echo** — N 回ごとの攻撃を会心（×2）にする（パッシブ）
- **Body / Cab Sim / Sub Woofer** — 装着中に最大 HP を増やす（パッシブ）

> 💡 **順序で結果が変わります**
> - チェーンは左→右に解決。右隣の modifier (×/+/−) が左隣ペダルの赤字を変える
> - `Driver → Booster (×2)` で赤字が倍に、`Cut (−3)` で削れて不発化
> - `Delay` の左隣がどのペダルかで指数的に伸びる組み合わせが生まれる

## マップの記号

| 記号 | 意味 |
|---|---|
| `@` | プレイヤー（▶◀▲▼ で向き表示） |
| `E` | 敵（HP バー付き、状態異常で色変化）。**マウスを乗せると詳細が見られます** |
| `P` | ピット（ペダル取り外しが可能なエリア） |
| `G` | ゴール（到達でクリア） |
| `#` | 壁 |

### 🕳 ピットは貴重な資源

- ペダルの **取り外し** はピット (`P`) の上でしか出来ません
- **スタート位置はピットではありません** — 最初から付け替えはできない状態で始まります
- **ピットは使い捨て**：一度立ち入って離れると崩れて消失します
- 「いつ、どのボードを編集するか」を計画して進むのがゲームの肝です

---

## 勝利と敗北

- **勝利**: ゴール (`G`) に到達
- **敗北**: HP が 0 になる

どちらもオーバーレイ表示が出ます。`F5` でリスタート。

## ローカルで動かす

リポジトリをクローンして `index.html` をブラウザで開くだけです。

```bash
git clone https://github.com/Shounen-Bob/fx-puzzle.git
cd fx-puzzle
open index.html
```

サーバーで動かしたい場合：

```bash
python3 -m http.server 8000
# → http://localhost:8000
```
