# fx-puzzle

エフェクターペダルを繋いで戦う、ブラウザで遊べるシレン風ローグライク。

## 🎮 今すぐプレイ

👉 **https://shounen-bob.github.io/fx-puzzle/**

ブラウザを開くだけ。インストール不要。

---

## どんなゲーム？

ギターやシンセで使う「エフェクターペダル」を信号チェーンに繋いで攻撃をカスタマイズしながら、ダンジョンのゴールを目指すターン制ローグライクです。

- **3 種類の攻撃** (突き / ビーム / オーラ) にそれぞれ **4 スロットの直列ペダルボード**
- ペダルの **順番** で結果が変わる (`Delay → Tremolo` と `Tremolo → Delay` で攻撃回数が違う)
- 装着はどこでも可、でも **取り外しは「ピット」の上だけ** — 一度刺したら戻るまで動かせない

## 操作方法

### 移動 / 攻撃

| キー | 動作 |
|---|---|
| `←` `↑` `↓` `→` | 移動 / 向き変更（壁にぶつかると向きだけ変わる） |
| `Q` | 突き (前 1 マス) |
| `W` | ビーム (前方 3 マス貫通) |
| `E` | オーラ (周囲 8 マス) |
| `Esc` | 構え解除 |
| `1` `2` `3` `4` | ペダル取り外し（ピット上でのみ有効） |

### 攻撃は 2 段階

1. `Q` / `W` / `E` を **1 回押す** → 構え状態 (ARM)。攻撃範囲がタイルに表示される（**ターン消費なし**）
2. **同じキーをもう一度押す** → 発射（ターン消費）
3. 違う攻撃キーを押せば構え切替、`Esc` で解除

### ボードの切り替え

画面下の `[Q]` / `[W]` / `[E]` ラベルをクリックすると、編集対象のボードが切り替わります。

### ペダルを装着する

- インベントリのペダルを **空きスロットへドラッグ&ドロップ**
- またはクリックで最初の空きスロットへ自動装着

## ペダル一覧（9 種）

### 属性付与

| アイコン | 名前 | 効果 |
|---|---|---|
| `D` | Distortion | 炎付与 / +2 ダメ / 燃焼 2 ターン |
| `P` | Phaser | 冷気付与 / 凍結 2 ターン |
| `O` | Octaver | 雷付与 / +1 ダメ / 麻痺 2 ターン |
| `T` | Pitch Shifter | 現在の属性を 1 段シフト |

### 攻撃回数

| アイコン | 名前 | 効果 |
|---|---|---|
| `L` | Delay | hits ×2 |
| `M` | Tremolo | hits +1 |

### 火力

| アイコン | 名前 | 効果 |
|---|---|---|
| `+` | Booster | ダメージ +3 |
| `V` | Overdrive | ダメージ ×1.5 |
| `E` | Envelope | ダメージ × (1 + 0.3 × 自分より前のペダル数) |

> 💡 **順序で結果が変わります**
> - `+ → V` と `V → +`：後ろにある `×1.5` が強い
> - `Envelope` は末尾に置くほど強い
> - `M → L` と `L → M`：攻撃回数が変わる

## マップの記号

| 記号 | 意味 |
|---|---|
| `@` | プレイヤー（▶◀▲▼ で向き表示） |
| `E` | 敵（HP バー付き、状態異常で色変化） |
| `P` | ピット（ペダル取り外しが可能なエリア） |
| `G` | ゴール（到達でクリア） |
| `#` | 壁 |

---

## 勝利と敗北

- **勝利**: ゴール (`G`) に到達
- **敗北**: HP が 0 になる

どちらもオーバーレイ表示が出ます。`F5` でリスタート。

## ローカルで動かす

リポジトリをクローンして `index.html` をブラウザで開くだけです。

```bash
git clone https://github.com/Shounen-Bob/fx-puzzle.git
cd fx-puzzle
open index.html
```

サーバーで動かしたい場合：

```bash
python3 -m http.server 8000
# → http://localhost:8000
```
